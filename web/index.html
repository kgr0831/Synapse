01 GRFGraph In build

The graph is the source. The TypeScript is output.

Round-tripping code back into nodes is where visual scripting tools die — half of it works, and then you lose data between two sources of truth. So we do not do it. The graph compiles one way, into TypeScript you can read but not edit, and the escape hatch is a Script node whose contents the compiler never touches.

Stable node identityEvery node carries a ULID, so moving it never changes the diff. Meaning lives in graph.json, coordinates in layout.json — an agent adding a node does not churn your positions.
Deterministic serialisationSorted keys, fixed float precision. The same graph produces the same bytes, which is what makes review and merge possible at all.
One document, two editorsHuman edits and agent edits are the same operations on a CRDT document, so they merge instead of collide — and one undo stack covers both.

02 AGTAgents Planned

An agent gets operations, not a filesystem.

Synapse exposes the project over MCP. There is no write-file tool — an agent adds a node, connects a pin, sets a component. It cannot corrupt the document because it never sees the document's syntax. Works from Claude Code, Cursor, or the panel inside the editor when your machine won't run a CLI at all.

OperationDoes
project.overviewScene, graph and asset tree — the first call
searchProject symbols, docs and templates, with citations
graph.patchadd_node · connect · set_pin_default · delete

asset.importglTF and textures, metadata extracted
build.runErrors returned against node IDs, not file lines
test.headlessN frames on a fixed input trace, then assert
history.revertEvery mutation checkpoints first

publish is deliberately absent. A person presses that button.

Verification is the pointWithout a way to check its own work an agent produces a plausible graph and stops. test.headless runs the game on a recorded input trace and asserts against the final state, so the loop closes: patch, run, assert, repair.
Signatures are not retrieved, they are looked upSearch finds what to use; the exact API shape comes from a generated symbol index filtered to your engine version. Nothing about a function's signature is left to a similarity score.

03 RUNRuntime Live

An engine is only as good as the worst GPU it runs on.
